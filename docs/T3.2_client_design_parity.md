## Thay đổi

- Auth: login/register/forgot/reset có form Enter, email/password validation, xác nhận mật khẩu, show/hide, loading/error. Khôi phục phiên qua refresh cookie HttpOnly; access token giữ trong RAM. Ghi nhớ email, clear Query cache khi đổi tài khoản/đăng xuất. Forgot/reset dùng API dev đã có; không dựng mail server.
- Onboarding: bento mobile, 4 cột desktop, danh mục thật, ảnh Stitch local, chọn ≥3, trạng thái selected, counter và nút Bỏ qua. PUT preferences/invalidate feed.
- Feed: desktop có nav, sidebar Xu hướng, khung 9:16 và Sắp phát tiếp; mobile có vertical snap, thanh action và camera đi tìm ảnh. HTML video phát URL clip published, chỉ active clip phát, mute/play/pause/seek, like/save/share thật. Phụ đề và waveform lấy timeline thật. Tracking click/like/share/save, watch_time khi phát và skip; heartbeat 10s, fetch keepalive với Bearer header khi rời/ẩn trang.
- Video detail: 2 cột desktop + transcript; mobile sheet native dialog. Player dùng clip published và chuyển timestamp clip ↔ video gốc đúng offset; heatmap toàn timeline, auto highlight >75, subtitles, summary/key moments/hashtags public đã duyệt, tìm bản ghi, tải .txt, rate và fullscreen.
- Search: tabs Văn bản/Hình ảnh, debounce/cancel request, ảnh thư viện/camera/drag-drop và preview, JPG/PNG/WebP ≤5 MiB, slider 50–100% gửi min_similarity ÷100. Metadata lấy VideoDetail thật; lọc duration/sort ngày ở client, grid/list desktop, timestamp Jump to Scene. 503 hiện lỗi, không trả kết quả mẫu.
- Discovery: bento mobile, desktop hero cao 520px + 2 card, trending carousel, Dành cho bạn. GET categories/videos/feed/history; category filter và cursor; chỉ hero lấy analysis, không gọi analysis cho từng card nhỏ.
- Thư viện: tabs likes/saved/history, sidebar desktop, grid/list, tìm tên, sort/cursor. Hồ sơ native dialog: username/preferences/email, PUT username và logout. Các thao tác thiếu API giữ disabled/empty rõ ràng.
- SVG Material Symbols chính xác từ Google, đúng viewBox/filled; font Inter và ảnh tham chiếu self-host. Không còn font ligatures/fake views/any/field raw_file_path hoặc view_count bịa.

## Contract gaps còn lại

1. **VideoDetail không có URL video gốc**: player phát published clip; timeline/key moments ngoài các clip chỉ báo chưa có nguồn phát, không tự đoán MinIO path. Không thể claim xem video gốc đầy đủ.
2. **Không có GET saved list, playlist CRUD, DELETE likes/history**, notification/quick login hoặc tạo highlight public: UI giữ cấu trúc nhưng khóa/báo chưa khả dụng. POST save hiện là interaction.
3. **Không có view/like counts hoặc public uploader metadata**: không hiển thị 1.2M/45K giả; tên hệ thống VidsAI, các số/dates lấy fields hiện có.
4. **Siamese/Milvus chưa nối**: visual API thực tế đã xác minh HTTP 503 AI_UNAVAILABLE /v1/search/completions; UI có thể upload và hiện lỗi đúng; chưa claim AI visual trả kết quả thật. Feed recommendation vẫn có fallback clips published thật.
5. History/likes/preferences ở backend còn adapter memory: có thể mất sau gateway restart; UI gọi API thật và không giả lập persistence.
6. Mini-GPT T1.6c quality limitation/CPU runtime giữ nguyên; task này không train lại model. Chưa đo video dài/VRAM/leak/visual <2s (T4.2/T4.3).

Không đánh đồng screenshot fixtures với pipeline AI thật. Nút không có API không báo thành công giả. Tiếp theo cần contract/backend nguồn phát gốc và các thao tác thư viện để đóng parity FULL.

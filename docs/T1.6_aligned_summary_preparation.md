## Label and source rules

`prepare_aligned_summary.py` preserves the editorial headline/sapo text except for stripping a small explicit publisher-prefix whitelist. A leading parenthesis is not removed generically: dates and unknown parenthesized content remain.

Candidates must have a sapo of at least5 words ending in sentence punctuation, with complete headline and summary targets of at most95 own-BPE tokens. All target word types and numeric spans must occur in the body. The **entire** clean body and synthetic ASR input must fit the512/96 profile for all3 formats. No source window is silently cut and no partial target is given a fabricated EOS.

The noisy source uses the existing CER0.1347 recipe and `seed=int(article_id[:8],16)`. This is the legacy measured-CER synthetic corruption, not a fresh estimate for real videos. Training/validation strips source edges exactly as production does. Inputs for title, summary and caption now all use the same body or its noisy version; the editorial sapo is no longer prepended as a hint for title/caption in this protocol.

**Lexical support is a screen, not factual verification.** It can retain reversed roles/relations and reject valid paraphrases. The strict screen favors short, lexically extractive examples; this is a small, biased development dataset. Caption still uses a headline surrogate rather than an independently human-authored key-moment caption. Long-input map/reduce quality and real-video domain adaptation remain separate limitations.

01 Kiến trúc & nguyên tắc

Toàn bộ AI tự code from scratch (không pretrained, không tokenizer ngoài, không pseudo-label). Chỉ dùng PyTorch làm nền tensor + autograd.

🧠 ai-core

Package Python thuần: primitives (attention, RMSNorm, SwiGLU, RoPE), AdamW, BPE, audio DSP, 6 model, training + datasets. Không dính web/DB.

⚙️ inference-service

1 process FastAPI :8001 nạp cả 6 model, hàng đợi GPU tuần tự, Bearer auth. Sản phẩm bàn giao của Phase AI.

🔗 gateway (Phase 2)

Go/Gin :8000 — public API, JWT người dùng. Chỉ gọi inference-service. Chưa build (AI-GATE chưa mở).

Luồng xử lý 1 video

upload → ingest (keyframe 1fps + wav) → orchestrator gọi lần lượt:
   /v1/vision   (ViT: category + embedding)
   /v1/asr      (CTC: transcript + segments)
   /v1/highlight(Fusion: điểm 0–100/giây)
   /v1/completions (Mini-GPT: tóm tắt, tiêu đề)
 → ghi DB → Admin duyệt → publish → Client thấy feed
i

4 nguyên tắc bất biến. (1) AI chỉ ra quyết định — FFmpeg xử lý file. (2) Client chỉ thấy dữ liệu đã duyệt. (3) AI đề xuất — Admin quyết. (4) Không gọi AI ngoài — “API key” là key nội bộ tự dựng sk-local-….

02 Cài đặt môi trường

Windows + PowerShell/Git-Bash. 1 venv dùng chung cho cả ai-core và inference-service. Dùng uv cho nhanh (hoặc python -m venv + pip).

Bước 1 — Tạo venv

# từ thư mục gốc dự án D:\traning_ai
uv venv .venv --python 3.11

Bước 2 — Cài PyTorch

# CPU (máy dev không GPU NVIDIA)
uv pip install --python .venv/Scripts/python.exe torch --index-url https://download.pytorch.org/whl/cpu

# GPU RTX 3060 (máy train/deploy) — CUDA 12.1
uv pip install --python .venv/Scripts/python.exe torch --index-url https://download.pytorch.org/whl/cu121

Bước 3 — Cài dependencies

# nền tảng train + test
uv pip install --python .venv/Scripts/python.exe numpy pyyaml pytest tensorboard
# data pipeline (khi có dữ liệu thật)
uv pip install --python .venv/Scripts/python.exe soundfile decord pillow
# inference-service
uv pip install --python .venv/Scripts/python.exe fastapi "uvicorn[standard]" python-multipart
!

Máy dev hiện tại chạy torch CPU (GPU là AMD, không CUDA). Code chạy + test xanh trên CPU; train thật đạt metric cần máy có RTX 3060 + CUDA.

04 Huấn luyện AI

Thứ tự dependency cứng (không đảo): T1.1 primitives → T1.2 data → T1.3 ViT+Siamese → T1.4 ASR → T1.5 Fusion → T1.6 Mini-GPT → T1.7 Two-Tower → T1.8 service. GPU train tuần tự trên 1 card.

4.1 Kiểm chứng toán học (bắt buộc trước khi train)

Gradient check, AdamW parity, SDPA parity, CTC parity, BPE roundtrip, overfit-1-batch.

cd ai-core
../.venv/Scripts/python.exe -m pytest ai_core/tests/ -v
# kỳ vọng: 49 passed

4.2 Train BPE tokenizer (cho Mini-GPT)

../.venv/Scripts/python.exe -m ai_core.scripts.train_bpe \
    --corpus "data/text/*.txt" --out data/manifests/bpe_vocab.json --vocab-size 8192

4.3 Chuẩn bị dữ liệu

# keyframe 1fps + loại frame đen + manifest (split 80/10/10 theo video)

    --videos data/raw/videos --labels labels.json \
    --out data/processed/keyframes --manifest data/manifests/vit.json

    --full data/raw/matches --highlight data/raw/highlights --out data/labels/highlight

07 Xác thực & token

AI_SERVICE_KEY là shared secret dạng sk-local-… — KHÔNG phải JWT, không hết hạn. So sánh chuỗi bằng nhau; sai/thiếu → 401 error envelope.

Sinh key

cd inference-service
../.venv/Scripts/python.exe -m app.gen_key
# → sk-local-2B7Q5D0kK4OjxbJVIYasVQNPvBCvUPU1gIEDi-4hJRk  (secrets.token_urlsafe(32))

Dùng key

  • Đặt cùng giá trị ở env inference-service và gateway.
  • Mọi POST /v1/* gửi header Authorization: Bearer ${AI_SERVICE_KEY}.
  • GET /health không cần token.
  • Đổi key = revoke tức thì: request với key cũ trả 401.

🔑 AI service key

🎫 JWT người dùng

09 Cách vận hành

⏳ Hàng đợi GPU tuần tự

Job GPU (vision/asr/highlight/completions) qua 1 asyncio.Queue + 1 worker → không tranh VRAM trên 1 card. Search/recommendation nhẹ, đi thẳng. Xem tải qua queue_depth ở /health.

🟢 Stub vs Thật

Registry nạp model nào có best.pt thì dùng thật, còn lại stub. stub_mode=true khi 0 model thật.

🟡 Degraded (không âm thầm)

Model thật nhưng real path lỗi (fetch audio hỏng, dtype, …) → tự fallback stub + tên model vào /health.degraded. Không bao giờ trả 500.

📉 Ngân sách VRAM

6 model fp16 nạp cùng ~120MB. Inference đỉnh ≤ 4GB (đo bằng torch.cuda.max_memory_allocated). Train ≤ 8GB.

Giám sát

# GPU đang bận / hàng đợi sâu?
curl -s http://127.0.0.1:8001/health | python -m json.tool
# theo dõi loss/metric khi train
tensorboard --logdir ai-core/runs
×

Luật AI-first. Phase 2/3 (backend/UI) chỉ bắt đầu sau khi AI-GATE mở (mục 11). Trong lúc GPU train qua đêm, chỉ được làm Phase 0 (contract/stub/docker-compose).

10 Lưu trữ & backup trọng số

Train xong sinh ra trọng số (checkpoint) — thứ quý nhất, tốn hàng chục giờ GPU. Dataset thô KHÔNG cần mang đi deploy.

💾 Trọng số (mang đi)

ai-core/checkpoints/{model}/best.pt — dict tự chứa {config, state_dict, bpe_vocab?, metrics} + sidecar asr_ctc/vocab.json, vit/classes.json.

🗂️ Dataset (KHÔNG mang)

data/raw · processed · labels chỉ dùng lúc train. Inference không đụng tới.

×

Dễ mất nhất. .gitignore loại checkpoints/, *.pt, data/ → trọng số KHÔNG nằm trong git. Clone lại máy khác / xóa thư mục = mất sạch. Phải backup thủ công.

Backup ngay sau train (ngoài git)

# giữ bản đạt metric trước khi train lại (train ghi đè best.pt/last.pt)
cp checkpoints/asr_ctc/best.pt backups/asr_ctc_seed1337_cer18.pt

# checksum để biết đúng bản
sha256sum checkpoints/*/best.pt > checkpoints/CHECKSUMS.txt

# đẩy lên nơi bền: MinIO (có sẵn trong stack) / S3 / Drive / HF Datasets (trọng số của BẠN — hợp lệ)
i

Không có online-learning. Serving chỉ ĐỌC trọng số, không tự đổi weight → chạy không mất data. Muốn AI “học thêm” = train lại offline → checkpoint mới → thay file + restart.

# T4.1 — Upload 2 GiB + real AI pipeline

Status: **DONE for the real upload → processed → review → publish → feed flow**, branch phase1-ai-core. This supersedes the earlier DEV-only result. T4.2/T4.3 were not started.

## Changed

- Nginx accepts 2049 MiB request bodies (2 GiB file plus multipart overhead), disables request buffering and uses 1800-second upload/proxy timeouts. Docker DNS is resolved dynamically so a recreated gateway does not leave CMS proxying to its old IP.
- Gateway limits file size to 2 GiB and request size to 2 GiB + 1 MiB; multipart memory is capped at 8 MiB and temporary multipart files are cleaned. File bytes stream to MinIO using 8 MiB parts, not an in-memory object map.
- PostgreSQL persists users/sessions/categories/videos/jobs/clips; MongoDB persists analyses/subtitles; Redis supplies TTL cache; Kafka delivers real events. Python ingest uses PyAV, extracts 1fps JPEGs and 16kHz mono PCM WAV, and reuses ai_core.audio.features.audio_features_per_second (64 dimensions). Temporary work is shared with inference and removed after processing.
- Gateway hosts the Go Orchestrator and cutter consumers in one process while sharing persistent adapters. No separate mock worker is needed for this flow.
- Inference loads all six read-only checkpoints, FORCE_STUB=0; missing checkpoints prevent startup. Vision/ASR/Highlight/Mini-GPT errors propagate as errors rather than synthetic results. Vision uses batches of 16, ASR uses 20-second windows and streams the shared WAV, and Fusion uses trained 120-second windows. No external AI service is called.
- Orchestrator passes each video's own 256-d ViT embeddings and 64-d audio features to Fusion. The old shared lastVisionEmb and incorrect 256-d-to-128-d vector upsert were removed. Siamese indexing remains T4.2.
- Timeline starts at second 0 and recommended peaks are strictly above 75. Clip average_score is computed from the actual timeline, weighted for fractional ranges and rounded to the existing PostgreSQL precision.
- Cutter runs real FFmpeg, checks storage/DB errors and only marks a cut draft after success. Failed cuts are rejected; unfinished/deleted source videos cannot be published. Video deletion hides clips and refreshes feed cache.
- Fixed PostgreSQL parameter-type inference in job status updates; transitions are checked against the real database. Fixed Kafka startup with an idempotent topic initializer and partition watching. Fixed MongoDB text-index language override so transcript metadata language=vi can be stored; existing documents are kept while the incompatible text index is replaced.
- Added Go HTTP/schema, upload limit, clip-score, job replay/feature-flow checks; PostgreSQL/MongoDB integration tests; Python checks for no stub fallback, windowing, strict threshold and real preprocessing; Playwright video_flow.spec.ts and an assert-based persistence script.
- MinIO's old registry image returned 401 and its archived binary returned 410. infra/minio/Dockerfile builds the original official source tag and retains its license. Source: [official release](https://github.com/minio/minio/releases/tag/RELEASE.2024-06-13T22-53-53Z).
- OpenAPI and all ports remain unchanged. No UI layout/style changes or training reruns.
